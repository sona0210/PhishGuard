# PhishGuard

## Project Overview

PhishGuard is a Python-based phishing email identifier tool.

The project analyzes email-related information and checks for common suspicious signs such as:

- Suspicious links
- Urgent or threatening language
- Requests for passwords or OTPs
- Unknown senders
- Sensitive information requests

It calculates a risk score and displays the risk level to help users understand possible phishing threats.

## Features

- Analyze suspicious email information
- Detect common phishing indicators
- Generate a risk score out of 100
- Display Low, Medium, or High Risk
- Provide basic safety advice
- Simple command-line interface

## Technologies Used

- Python 3
- String handling
- Conditional statements
- Loops
- Basic risk scoring logic

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python phishing_email_identifier.py
```
5.Enter the required email information.
6Check the detected phishing signs and risk assessment.
